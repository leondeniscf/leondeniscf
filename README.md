## 🚀 What I'm building

### SGI Sentinela: Integrated Management SaaS for field-service contractors
A multi-tenant, white-label platform (HSE + HR/Payroll + crew mobilization + quality + billing) **in production for paying customers**.

- **39 modules** in a single client deployment: safety inspections, digital job hazard analysis with signatures, health exams, training & certificate control, fleet, daily work reports, audit-ready employee dossiers and executive KPI dashboards
- **Android field app** (Capacitor, offline-first) with over-the-air updates and push notifications
- **AI features with the Claude API:** résumé screening, root-cause (Ishikawa) assistant, regulatory suggestions for findings, document OCR
- **Integrations:** fleet telematics API, external JSA system sync, QR-code public document verification
- **Cloud back end:** serverless API gateway on Cloud Functions, Cloud Tasks background jobs, Secret Manager, least-privilege IAM, tenant isolation, LGPD (Brazilian GDPR) compliance
- **570+ commits in ~4 months** for one client rollout

> 🔒 Client code lives in private repositories. Happy to give a live demo on request.

### Other projects
- **HR lifecycle system** (React + TypeScript + Firebase): Python ETL merged scattered spreadsheets into one record per employee (~1,200 people), admission Kanban, scheduled alert engine for legal deadlines
- **Utility compliance analytics:** penalty/SLA monitoring models and inspection non-conformity dashboards for major power utilities
- **Email-driven automation:** reads incoming emails, extracts certificates, validates electrician qualifications and updates the cloud database
